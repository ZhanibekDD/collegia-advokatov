# Коллегии адвокатов Республики Казахстан

Современный двуязычный портал для поиска адвоката, выбора правового маршрута и доступа к профессиональной юридической информации в Казахстане.

## Что реализовано

- премиальный официальный визуальный стиль;
- полная русская и казахская локализация интерфейса;
- поиск по региону и направлению права;
- маршруты помощи для типовых правовых ситуаций;
- блок профессиональных гарантий и стандартов;
- полезные материалы и интерактивный FAQ;
- адаптивная верстка для компьютеров, планшетов и телефонов;
- SEO-метаданные для русского и казахского поиска;
- доступные элементы управления и поддержка `prefers-reduced-motion`.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm run lint
npm test
```

## Стек

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Vinext и Cloudflare Workers.
