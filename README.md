## О проекте

Презентационная версия современного сайта для **Жетісуской областной коллегии адвокатов**.

Портал помогает жителям области Жетісу:

- быстро найти адвоката по ФИО или номеру лицензии;
- посмотреть опубликованные сведения об адвокате;
- перейти к карточке специалиста и доступным контактам;
- определить маршрут правовой помощи по жизненной ситуации;
- пользоваться интерфейсом на русском и казахском языках.

> **Региональный фокус:** пользовательская часть сайта ограничена областью Жетісу. Адвокаты других регионов Казахстана в каталоге не показываются.

## 🗺️ Региональный фокус

Сайт создаётся именно для **Жетісуской областной коллегии адвокатов**, поэтому в интерфейсе убрана прежняя концепция республиканского портала:

- нет формулировок «все адвокаты Казахстана»;
- нет выбора 20 регионов;
- каталог фильтруется по значению `область Жетісу`;
- прямые карточки адвокатов других регионов не открываются;
- SEO и тексты ориентированы на **Жетісу / Талдыкорган**;
- раздел «Регионы» преобразован в страницу **«О коллегии»**.

---

## 🛡️ Источник и корректность данных

Каталог формируется из открытого набора Министерства юстиции Республики Казахстан:

**«Список адвокатов» — портал открытых данных data.egov.kz.**

Используемая версия источника обновлена владельцем **08.07.2025** и помечена как требующая актуализации. Поэтому сайт отдельно предупреждает пользователя: перед заключением соглашения необходимо дополнительно проверить текущий статус лицензии и членство адвоката в территориальной коллегии.

Сайт не создаёт вымышленные рейтинги, специализации или оценки адвокатов.
