# Коллегии адвокатов Республики Казахстан

Двуязычный портал для поиска адвокатов и навигации по юридической помощи в Казахстане.

## Официальный каталог

Каталог содержит 6 005 записей из открытого набора Министерства юстиции Республики Казахстан:

- ФИО;
- регион;
- номер и дата выдачи лицензии;
- дата вступления в коллегию;
- адрес и контакты.

Источник: https://data.egov.kz/datasets/view?index=advokattar_tizimi14

Используется версия v15, обновлённая владельцем 08.07.2025. На портале открытых данных набор помечен как требующий актуализации, поэтому перед заключением соглашения необходимо дополнительно проверить текущий статус лицензии и членство в территориальной коллегии.

## Что реализовано

- поиск по ФИО, лицензии, адресу и контактам;
- фильтрация и счётчики по всем 20 регионам;
- пагинация и отдельные карточки записей;
- навигатор правовой помощи;
- русская и казахская версии интерфейса;
- адаптивная вёрстка и профессиональные Lucide-иконки;
- нейтральный фирменный знак без использования государственного герба или символики РКА.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash

npm run dev
```
